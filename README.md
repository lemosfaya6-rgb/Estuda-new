# Estuda+

Aplicativo simples e profissional para criação de trabalhos investigativos escolares.

## Objetivo

O Estuda+ ajuda o estudante a criar trabalhos escolares organizados a partir de um tema, número de páginas, nível de linguagem e orientações adicionais.

Além do trabalho, o projeto foi pensado para preparar o estudante para a apresentação, com perguntas e respostas de defesa.

## Funcionalidades iniciais

- Formulário para criação do trabalho
- Níveis: Fácil, Médio e Avançado
- Geração de estrutura escolar
- Perguntas e respostas para defesa
- Interface responsiva
- Arquitetura preparada para integração com IA
- Português como idioma principal

## Estrutura

- `index.html` — aplicação principal
- `style.css` — estilos
- `app.js` — lógica da interface
